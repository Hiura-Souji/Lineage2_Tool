# 新天堂II 帳號輔助工具

用來管理新天堂II（Lineage II 台服）多組遊戲帳號的輔助工具。可記錄帳號、角色與 OTP，一鍵複製、半自動登入遊戲，並附 L2 視窗小工具與組態備份還原。

- 開發語言：AutoIt 3（32 位元），介面使用 AUI 函式庫
- 資料儲存：SQLite3 Multiple Ciphers（ChaCha20-Poly1305）整檔加密
- 版本日期：2026.10.27
- 作者：SHIWASU KAKERU（師走　駆）
- 執行權限：需要系統管理員（`#RequireAdmin`）

---

## 特色

- 不需安裝額外軟體，解壓即用。
- 密碼與 OTP 金鑰加密保存，資料庫沒有主金鑰就無法讀取。
- 可記錄帳號、角色資訊，並協助登入遊戲。
- 連網功能只用來檢查本軟體更新、載入網頁登入與酷碰登錄頁。

## 主要功能

### 帳號管理

| 功能 | 說明 |
|---|---|
| 卡片介面 | 以卡片顯示帳號、角色代表、OTP 與倒數圓圈；可依「所屬」、群組篩選 |
| 複製 | 雙擊卡片複製 OTP；右鍵選單可複製帳號、密碼、OTP、單筆資料 |
| 新增／編輯 | 欄位：帳號 ID、所屬、帳號、角色代表、備註、卡片顏色、密碼、OTP Key |
| 卡片顏色 | 可自訂卡片色塊，也可還原為原始色 |
| 收藏與群組 | 星號收藏；可建立、刪除自訂群組，並加入或移除帳號 |
| 手動排序 | 完整管理可上移、下移、恢復 ID 順序；閒置後批次寫入資料庫 |
| 完整管理 | 以清單檢視全部帳號、批次操作；可吸附在卡片介面右緣，並跟著移動 |
| 匯入／匯出 | 內建 CSV / XLSX / XLS 讀寫（純 AutoIt），批次作業有進度視窗 |

右鍵選單項目：複製帳號、複製密碼、複製 OTP、複製單筆資料、編輯資料、更改顏色、切換收藏、登入帳號、網頁登入。

### 登入遊戲

- **登入帳號**：半自動登入，透過 UI Automation 操作 NC 啟動器 PURPLE 視窗。
- **網頁登入**：內嵌 WebView 開啟 NC 登入頁。滑鼠側鍵可上一頁、下一頁。
- **批次登錄酷碰序號**：在完整管理批次登錄序號。

### OTP

- 內建 TOTP（RFC 6238，HMAC-SHA1，6 位數、30 秒），自動更新。
- 可直接複製目前驗證碼。

### L2 小工具（齒輪圖示）

卡片介面的「重新整理」旁與完整管理右下角都有入口。

**視窗管理**（有勾選＝批次；沒勾選＝目前選取的那一列）

- 禁止／允許縮放（拉邊框）
- 禁止／允許最大化（按鈕、雙擊標題、拖到螢幕上緣）
- 禁止／允許拉到螢幕邊緣最大化（保留縮放與最大化按鈕）
- 強制關閉指定視窗（進程），或關閉全部
- 保護：被保護的視窗不會被任何操作影響
- 點選清單項目時，會用框線圈出對應視窗並讓工作列圖示閃爍，方便辨識
- 每次操作都會驗證是否真的生效，並回報成功、略過、未生效的數量

**組態備份與還原**

- 備份新天堂II 安裝目錄 `system` 資料夾下的 `*.ini`（視窗大小與位置、遊戲內設定）
- 備份存放於程式資料夾的 `iniBak\年月日_時分秒\`
- 還原前會先自動備份目前設定（`_BeforeRestore`）
- 遊戲執行中不允許還原
- 還原後可能會不符合當前版本，進而影響到開啟遊戲，還原後請先執行 `檢查檔案`

### 安全性

| 項目 | 說明 |
|---|---|
| 整檔加密 | `lineage_data.db` 以 32 位元組主金鑰（DEK）加密，DEK 不寫入原始碼或資料庫 |
| 金鑰包裝 | 使用者密碼經 PBKDF2-HMAC-SHA256（600,000 次）導出金鑰，包裝 DEK 後存於 `lineage_data.key` |
| 登入保護 | 可在抽屜選單開關；停用時改用 Windows DPAPI（綁定目前 Windows 使用者）免密碼開啟 |
| 換電腦或換帳號 | DPAPI 副本解不開時，自動改為登入視窗，登入一次後恢復免密碼 |
| 復原金鑰 | Base32 顯示，只在建立時出現一次，忘記密碼時用來重設管理員 |
| 舊版轉換 | 偵測到原版 `eL2.mdb` 時，須先以原本帳密登入，驗證通過才會轉入新資料庫 |

> 請務必保存復原金鑰，並備份 `lineage_data.db` 與 `lineage_data.key`。兩者缺一不可。

## 使用方式

1. 執行程式。第一次使用會要求建立管理員密碼，並顯示**一次性的復原金鑰**，請立即抄寫保存。
2. 按「新增／編輯帳號」輸入遊戲帳號資料。
3. 在卡片上雙擊複製 OTP，或右鍵選擇登入帳號、網頁登入。
4. 需要整理大量帳號時，從抽屜開啟「完整管理」。
5. 需要管理 L2 視窗或備份組態時，按 齒輪 圖示開啟小工具。

### 從舊版（2.x，`eL2.mdb`）升級

1. 把 `eL2.mdb` 放在程式資料夾。
2. 啟動後以舊版的登入帳號與密碼登入。
3. 驗證通過後，遊戲帳號資料會一次性轉入新資料庫。

### 啟動流程

| 狀態 | 行為 |
|---|---|
| 有金鑰檔，且停用登入保護 | 以本機 DPAPI 副本自動解鎖 |
| 有金鑰檔，且啟用登入保護 | 顯示登入視窗 |
| 沒有金鑰檔，但有資料庫 | 顯示復原金鑰視窗，重設管理員 |
| 有 `eL2.mdb` | 以舊帳密登入，驗證後轉換 |
| 以上皆無 | 建立管理員 |
